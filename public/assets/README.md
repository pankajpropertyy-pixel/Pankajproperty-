# Pankaj Property - Hero Video Assets Directory

Place your uploaded hero MP4 video here with the name:
`hero-video.mp4`

File path:
`public/assets/hero-video.mp4`

When placed here, it will automatically serve at:
`/assets/hero-video.mp4`

The hero section will automatically detect and play this file edge-to-edge with seamless looping and autoplay.
You can also connect or test any local MP4 file instantly via the in-app "Connect Hero Video" modal on the live site!
